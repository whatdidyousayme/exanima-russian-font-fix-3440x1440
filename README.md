# Exanima: русский шрифт для 3440×1440

Небольшая правка метрик основного русского шрифта для полноэкранной игры в разрешении 3440×1440. Правка проверена с Exanima 0.9.5.2 и русификатором ZoG 1.5.6.

## Установка

1. Установите Exanima 0.9.5.2.
2. Установите русификатор ZoG 1.5.6 в папку игры.
3. Скачайте этот репозиторий архивом и распакуйте в любое удобное место.
4. Запустите Install.bat и выберите папку с Exanima.exe.
5. Запустите игру в полноэкранном режиме с разрешением 3440×1440.

Патчер сохраняет резервную копию исходного Exanima.exe. Он применяет изменение только к проверенной сборке и завершает работу без изменений, если версия файла отличается.

## Откат

Закройте игру и замените Exanima.exe резервной копией Exanima.exe.before-font-fix-*.bak из папки игры.

На других разрешениях с соотношением 21:9 правка не тестировалась; можете попробовать.

## Что изменено

Скорректированы метрики шрифта в Exanima.exe; после этого русский текст стал читабельным в полноэкранном режиме. Перевод и остальные игровые ресурсы не менялись.

Всю работу выполнил ChatGPT.
